Upload the icon and choose three to five mobile screenshots from the five provided.

Every image is below 2 MB; together they use less than 1 MB. No SVG files are included. Paste long-description.txt into the long description field; short-description.txt supplies the one-line description.

The screenshots capture the actual mobile UI. Zara, Tobi, invitation codes and completed results are sample data from an isolated, temporary in-memory database. No production player data was used. The icon is a raster rendering of the existing green-and-cream WP tile identity.

Deploy the active-game switcher, head-to-head records and mobile New game button fix before submitting this listing. Verify the real LagosLife embed with its test identity first. Ayo progress is device-local; unsubmitted arrangements persist in the current browser tab until the board changes. Friend games expire seven days after creation. Head-to-head counts cover completed friend games, showing the latest 20 results.

The listing form says draft pictures are removed after 30 days without a listing change. Keep this local package for re-uploading.
